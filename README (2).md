# لعبة الذاكرة الوردية 🎀 (Pink Memory Game)

تطبيق لعبة ذاكرة تعليمية وتفاعلية موجهة للتوعية بسرطان الثدي، ومناسبة للفعاليات المدرسية والأنشطة الصحية.

## 🌟 ميزات اللعبة
- **30 بطاقة (15 زوجاً متطابقاً):** رموز ورسومات عالية الجودة.
- **معلومات صحية موثوقة:** تظهر نافذة توعوية عند اكتشاف كل زوج متطابق.
- **تأثيرات تفاعلية 3D:** حركة تدوير البطاقات المؤثرة ورمي الشرائط الاحتفالية عند الفوز.
- **متوافقة:** تعمل بمرونة على أجهزة الجوال، الحاسوب، والشاشات التفاعلية المدرسية.

## 🛠️ فريق العمل والاعتماد المدرسي
- **تصميم وتنفيذ:**
  - المعلمة لينا مصاروة
  - المعلمة فاطمة عبيدات
  - المعلمة سلسبيل حمادنة
  - لجنة الهلال الأحمر
- **إشراف مديرة المدرسة:** هناء عبيدات
- **المدرسة:** مدرسة حرثا الثانوية الشاملة المختلطة

## 🚀 كيفية النشر على GitHub Pages

1. قم بإنشاء **New Repository** في حسابك على GitHub باسم `pink-memory-game`.
2. ارفع الملفات الأربعة الموجودة في هذا المجلد (`index.html`, `styles.css`, `script.js`, `README.md`).
3. اذهب إلى إعدادات المستودع **Settings** -> **Pages**.
4. اختر الفرع `main` أو `master` ثم انقر **Save**.
